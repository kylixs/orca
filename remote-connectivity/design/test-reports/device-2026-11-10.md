## 3. iOS build blocker (environment)

The installed Xcode 16.4 / iOS 18.6 SDK is too old for the Expo SDK 55 package versions in this checkout. Four independent failures were observed, so the build cannot be completed by a local setting change:

1. `expo-modules-core` declares Swift 6.0 and uses isolated conformances (`extension X: @MainActor Protocol`), a Swift 6.2 feature. Xcode 16.4's Swift 6.1 rejects it as `unknown attribute 'MainActor'`.
   - `ios/Core/Views/SwiftUI/SwiftUIHostingView.swift:45`
   - `ios/Core/Views/SwiftUI/SwiftUIVirtualView.swift:196`
   - `ios/Core/Views/ViewDefinition.swift:121`
2. `expo-router` uses iOS 26 SDK APIs:
   - `RouterToolbarItemView.swift:175` `UIBarButtonItem.Badge`
   - `RouterToolbarModule.swift:98` `UIBarButtonItem.Style.prominent`
3. `expo-notifications` uses `DateComponents.isRepeatedDay` (iOS 26)
   - `DateComponentsSerializer.swift:9`
4. `expo-image-picker` uses `PHAsset.contentType` / `PHAssetResource.contentType` (iOS 26)
   - `MediaHandler.swift:300,309`

Temporary patches in `node_modules` (three isolated conformances and the two iOS 26 use sites) were applied to see how far the build could go, then all patched files were restored. Even with those patches the build still fails on the iOS 26-only photo APIs. A build requires Xcode 26 / iOS 26 SDK. The full logs are `logs/ios-xcodebuild-1.log` through `logs/ios-xcodebuild-4.log` (copied from `/tmp/orca-xcodebuild*.log`).

Consequence: iOS acceptance for every feature (Save to Files, share sheet, UTI/iPad anchor, iOS terminal gestures, iOS WebView safety) is BLOCKED, not PASS.

## 6. Top issues

1. **Android HTML preview executes `javascript:` links.** `javascript:alert(1)` opened a native JS dialog instead of being rejected with the documented toast. Evidence: `screenshots/android-71-js-link-toast.png`.
2. **Filter chips are laid out as full-height columns.** The All/Code/Docs/Media/Images/Other row occupies most of the viewport, hiding results, especially with the keyboard open. Evidence: `screenshots/android-11-files.png`, `android-66-filter-docs.png`.
3. **Terminal selection highlight and copied text can disagree.** A multi-row highlight copied only `src/main.ts:42`. Evidence: `android-51`, `android-53`, `android-55`. Needs manual reproduction with real touches.
4. **The save toast swallows touch input** until dismissed. Evidence: `android-19`-`android-22`.
5. **iOS cannot be built or accepted on this machine.** Xcode 16.4 / iOS 18.6 SDK vs Expo SDK 55 packages using Swift 6.2 and iOS 26 APIs (expo-modules-core, expo-router, expo-notifications, expo-image-picker).
