## 3. 探索性测试清单（每模块逐项，对照原型）

对**每个页面**核对：

1. **页面/导航**：入口可达、面包屑、返回、底 tab 高亮、404/403 形态
2. **菜单**：侧栏折叠/「更多」sheet 项齐全、点击目标 ≥44px、滚动不遮挡
3. **列表**：列转卡片完整性（状态/时间/操作）、空态、加载态、失败态+重试、排序/筛选 chips 横滑
4. **按钮/操作**：主/次/危险按钮布局、置灰条件、确认弹框（取消零请求）、toast 文案逐字
5. **表单/字段**：全屏 sheet、字段聚焦不缩放（≥16px 输入）、必填校验、错误行内展示、长文本截断
6. **设计一致性**：STYLEGUIDE token（颜色/字号/间距）、与桌面文案一致、无横向溢出

每项记录：页面/项/期望/实际/截图；FAIL → 台账 → 修复令。
