## 流程整改（用户指令驱动）

1. **缺陷台账**：本文件为唯一登记处，新问题先进台账再派修。
2. **链路优先**：W9 双线（桌面/Orca Web 黄金旅程）从收口位提为集成先锋；每波集成后先跑链路冒烟。
3. **分层规则**：mock 层测试不得作为链路步骤覆盖依据（自查审计 agent 产正式方案中）。
4. **不让用户重复挫败**：每个用户报告的问题，修复回归绿之前在台账保持🔴/🟡；给用户的操作指引必须先在主会话侧实测验证再给出。
