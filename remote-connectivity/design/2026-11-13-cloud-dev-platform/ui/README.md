# Orca Cloud 云端开发平台 · 高保真 HTML 原型

## 1. 文件与打开方式

- 原型文件：[`prototype.html`](./prototype.html)
- 单文件、自包含：CSS / JavaScript / SVG 图标全部内联，不依赖外部 CDN、图片或网络字体。
- 设计基准视口：1440 × 900；1280 × 900 下可用，不提供移动端布局。
- 直接用浏览器打开即可，页面通过 hash 路由切换，不会整页刷新。

启动后默认进入 `#/login`。登录页不校验账号密码，输入任意账号与密码后展示约 1 秒加载态并进入工作台；如需查看密码错误的内联错误态，请在密码框输入 **`wrong`**（隐藏演示路径）。

```text
#/login                         登录页
#/workbench                     工作台（登录后的默认首页）
#/projects                      我的项目
#/project/payment-service       项目视图（也可使用 order-center 等其他在线项目 ID）
#/hosts                         主机管理（管理员）
#/relays                        中继管理（管理员）
#/members                       项目授权（管理员）
#/audit                         审计日志（管理员）
#/diagnostics                   连接诊断
#/settings                      下载策略（管理员）
#/forbidden                     403 无权限页
```

> 页面间的角色门禁是前端演示：管理员默认拥有全部导航；开发者仅显示「工作台」「我的项目」。在开发者状态下直接访问管理路由会被带到 `#/forbidden`。真实系统中管控面权限必须由服务端校验，隐藏入口不作为安全边界。

## 2. 平台形态说明

「云端开发平台」本身是 **Web 前后端分离系统**。本原型展示的是平台 Web 前端（工作台 + 管控台）的高保真稿；生产环境中，项目视图的终端、Claude 会话、文件浏览器与编辑器由 **Orca Cloud 桌面客户端**承载：客户端登录平台、获取项目对应的直连地址与中继地址以及短期连接凭证，然后**自行建立链路**（直连优先，不通再经中继）。平台不代理业务流量。

为了让评审可以在一份原型中走完登录 → 工作台 → 打开项目 → 连接诊断的完整链路，P3 项目视图也放在本文件中，并保留客户端内的 Orca 风格布局。P3 顶部的 40px 平台条对应平台层信息（项目、分支、连接线路、主机、断开连接），其下两行工作区标题栏与三栏 IDE 对应桌面客户端体验。

本原型中的用户、项目、主机、审计事件、权限、终端输出均为演示数据，没有后端、真实 LDAP 或真实连接。

## 3. 页面清单与关键状态

### P1 登录页 `#/login`

- 居中 400px 卡片，几何 SVG 标记 + 「ORCA CLOUD」字标。
- 域账号、密码输入；密码支持显示/隐藏。
- 登录主按钮为全宽 36px，点击后进入加载态「正在验证域账号…」，约 1 秒后进入工作台。
- 隐藏演示：密码输入 `wrong` 时，加载结束后显示红色内联错误与密码框红边，不使用 toast，也不弹系统对话框。
- 底部包含《平台使用规范》文案和灰色「内网直连 / 外网访问」小徽标。

### P2 工作台 `#/workbench`

- 欢迎区：「下午好，张伟」与进行中项目提示。
- 4 个统计卡：进行中项目 3、今日会话 7、可用主机 12、待审批下载 2。
- 最近项目 3 张卡片：项目名、仓库路径、主机徽标、分支徽标、最近使用时间、在线状态与「打开」按钮；悬停时边框加深。
- 全部项目表格：项目 / 仓库 / 主机 / 可见范围 / 最近使用 / 状态 / 操作；支持按在线、离线筛选。
- 主机离线时整行置灰，操作区显示「主机离线」并禁用打开；悬停提示「主机离线，无法打开」。
- 底部说明「仅显示你有权限访问的项目」。
- 顶部提供全局搜索（项目 + 主机）、通知、新建项目；新建项目包含完整登记表单，提交后会插入工作台项目表格并更新进行中项目计数。
- 通知面板支持「全部标为已读」。

### P2b 我的项目 `#/projects`

- 复用项目数据，提供项目名 / 仓库 / 主机搜索、主机状态与可见范围筛选。
- 支持空结果状态与刷新反馈；表格沿用离线置灰与打开限制。

### P3 项目视图 `#/project/payment-service`

顶部平台条（40px，`#fafafa`）：

- 返回箭头、项目名、当前分支。
- 连接状态徽标在页面中央，点击后可切换四种演示状态：直连 18ms / 中继 62ms / 正在选择线路 / 连接失败。
- 右侧主机名、用户头像、「断开连接」文字按钮；断开操作使用自定义确认框。

Orca 风格标题栏：

- 红黄绿窗口点、项目名与分支、`Claude` / `Terminal 1` / `Terminal 2` / `browser` 标签页，选中项有 2px 品牌色下划线。
- 右侧分屏与新建标签页图标。新建标签页会真实新增 Terminal 3（可继续新建）。

三栏主体：

- 左栏 240px：WORKSPACES 列表（feat/refund、main、hotfix/login）、当前工作区高亮、「+ 新建工作区」。
- 中栏：深色终端（`#1e1e1e`，等宽 12px）展示 Claude Code 会话，包括用户指令、Read / Search / Edit / Bash 工具调用、测试结果、已完成修改与闪烁光标；Terminal 1/2 与 browser 有独立内容。
- 右栏 300px：文件树，目录可展开/折叠；文件行悬停显示 `⋯` 菜单。右键文件或点击 `⋯` 打开上下文菜单，点击空白处或 Escape 关闭。
- 文件菜单：打开、在编辑器中打开、复制路径、下载（灰显 + 锁 + 「需审批」）、重命名、删除。
- 悬停「下载」显示 tooltip：「当前项目已禁止下载文件，如需导出请提交审批。」；点击该项或文件面板右上角的锁图标，打开「下载已被禁用」对话框。主按钮「提交下载申请」一期禁用，关闭为次按钮。
- 文件行可打开只读代码预览；重命名与删除均有自定义确认/表单，无 `alert()` / `confirm()`。
- 连接状态「正在选择线路」在终端区显示加载遮罩与骨架；「连接失败」显示错误面板：`HOST_UNREACHABLE`、三段诊断、「重试」「查看诊断」。重试会先回到加载态再恢复直连。
- 连接弹层底部提供「查看连接诊断」，可进入 P7。

### P4 主机管理 `#/hosts`

- 面包屑「平台设置 / 主机」；顶部「生成注册命令」次按钮与「注册主机」主按钮，两个入口都打开同一个添加向导。
- 表格列：主机名 / 地址 / 路由键 / 系统 / 网络位置 / 连接路径 / 心跳 / 状态 / 操作。路由键以 mono 徽标展示（如 `ip-10.20.3.18`），默认取直连 IP（主机名不可靠），可显式配置并随 IP 变化自动跟随。
- 在线、维护中、离线三种状态；支持按名称/地址搜索，以及状态、网络位置筛选；统计数量随状态变更更新。
- 点击行或「查看」打开右侧抽屉：主机 ID、地址、系统、网络位置、Orca 版本、协议版本、承载项目、注册时间、公钥指纹、直连/中继延迟；「路由与中继」区展示路由键、路由键来源（自动派生 · 跟随直连 IP）与中继端点 SNI（形如 `ip-10.20.3.18.relay.local`，仅是中继的路由标签，无 DNS 解析）。
- 抽屉支持「进入维护模式 / 退出维护模式」，操作后列表与顶部统计同步更新；「下线主机」走自定义确认，确认后状态变为离线。
- 注册主机向导展示一行安装命令（`bash <(curl -fsSL http://platform.internal:18787/install/host.sh?token=…)`，令牌一次性、24 小时内有效并内嵌于命令）、复制按钮与三步说明。

### P4b 中继管理 `#/relays`

- 与主机分开管理的独立页面（接口 `/v1/relays`，仅管理员可见），不在主机页混排。页头说明：中继自行向平台注册，平台只登记与分配，不代理业务流量；客户端直连中继。
- 统计卡：在线中继（2 / 注册 3 个）、承载路由（8 个 routeKey）、路由同步窗口（30 秒 · 超窗剔除）、窗口期外剔除（近 7 天 1 个）。
- 支持按节点 ID / 可拨地址搜索与状态筛选。表格列：节点 ID（含注册来源 IP）/ 客户端可拨地址 / 注册方式（自动注册）/ 路由同步 / 最近同步 / 承载路由 / 状态 / 操作。
- 点击行或「查看」打开右侧抽屉：客户端可拨地址、注册方式、注册来源 IP、内部令牌指纹（脱敏，仅显示尾 4 位，如 `m114-…a7f2`）、注册时间、路由同步状态与窗口、承载的 routeKey 列表（如 `ip-10.20.3.18`）；可复制可拨地址。
- 顶部「添加中继」打开向导弹层，生成一行安装命令 `bash <(curl -fsSL http://platform.internal:18787/install/relay.sh?token=…)`（内部令牌一次性、24 小时内有效、内嵌于命令），并提示可拨地址缺省取注册来源 IP，NAT 后需用 `RELAY_PUBLIC_HOST` 显式指定。
- 演示数据：relay-01（在线，100.67.197.59:7443）、relay-02（在线）、relay-03（离线，同步超窗）。
- 页底说明：中继只做 TCP 转发，按 SNI 路由标签查表转发，不解析协议、不解密；路由表由平台单向同步且只包含已注册开发机。

### P5 项目授权 `#/members`

- 左侧窄项目列表（6 个受管项目）；右侧显示 payment-service 详情，点击其他项目会刷新标题、基本信息、成员与下载策略。
- 基本信息表单：项目名、仓库地址、主机、只读目标路径（可复制）、负责人组、可见组；保存与重置有内联反馈。
- 成员与组表格（主体 / 类型 / 打开项目 / 终端 / Agent / 文件只读 / 文件写入 / 下载 / 来源 / 操作）：
  - 权限以勾选标记展示。
  - 下载列全部未勾选，显示空复选框 + 锁图标，并说明需在下载策略中开启与审批。
  - 来源展示「直接 / 继承」。
  - 信息条说明下载权限需在下载策略中单独开启，审批流为二期。
- 「添加成员」打开表单：用户 / LDAP 组切换、主体选择、权限勾选；下载权限在表单中锁定，不能随成员添加开启。
- 移除成员使用自定义确认。
- 项目级下载策略：禁止下载（默认）/ 仅审批后允许（二期，禁用）/ 允许下载，保存后更新当前项目徽标与提示。

### P6 审计日志 `#/audit`

> [U66-review-r2 N-7] 本节按二轮修订后的原型同步（三态 / 起止时间 / 默认 7 天 / 新列）。

- 顶部可见性说明：审计员 / 管理员可见全部用户与项目的事件；本人自查不在本期；内容摘录仅在摘录开关开启时可见。
- 可折叠「覆盖范围与限制」：列出可捕获面（桌面 `files.readChunk` 客户端自报、宿主 `browser.download`、移动端保存、应用内复制、宿主拒绝与前端拦截）与不可捕获面（带外传输、Finder/Explorer、截图/OCR、浏览器另存为、跨域 iframe、键盘 Ctrl+C、离线/重启窗口），并声明“审计链保证记录不被篡改，不保证记录完整”“缺口可见性 best-effort”。
- 页头状态：日志采集正常 + 单主机审计缺口（如 `dev-node-07` 丢弃 3 条）；二者是总体与单主机两个维度。
- 筛选行：关键字（文件名 / 路径 / 账号 / 项目，2–128 字符）、时间范围预设（24 小时 / 默认 7 天 / 最大 31 天）、起始时间与结束时间（`datetime-local`）、操作类型（含「下载族」`file_download+download_blocked` 与「复制族」`file_copy`）、用户（域账号精确）、项目、主机（项目与主机独立 AND）、文件名（1–128 字符）、结果（成功 / 失败 / 拒绝三态）；查询、清除均可用。
- 表格上方：审计日志保留 180 天，导出需审批；内容摘录开关默认关闭（关闭时仅展示指纹，开启后才展示 ≤1KB 有界前缀并标注截断）；导出按钮禁用，悬停显示二期提示。
- 表格列：时间 / 用户 / 操作 / 项目或主机 / 文件·大小 / 结果 / 详情。时间使用相对时间，`title` 提供绝对时间。
- 操作列：文件事件展示下载 / 复制类型徽标与可信度徽标（主机确认 / 客户端自报 / 推断）；复制行可「展开」查看摘录（默认关闭）、sha256 与复制字符 / 字节数。
- 点击行或「查看」打开右侧抽屉：事件、时间、用户、项目或主机、结果、可信度、复制长度、来源 IP，以及 traceId、会话 ID、连接路径、耗时、错误码与附加说明。
- 抽屉支持复制 traceId。

### P7 连接诊断 `#/diagnostics`

- 从项目视图的连接弹层或连接失败面板进入；普通开发者也可访问。
- 顶部摘要：payment-service、feat/refund、`RELAY_FALLBACK`、relay-01（含 SNI 路由标签 `ip-10.20.3.18.relay.local`）、会话 ID、总耗时 1,269ms。
- 时间线 6 步：申请连接凭证 23ms 成功；无凭证 TCP 预检直连 10.20.3.18:6768 800ms 超时；备用直连跳过；无凭证预检中继 relay-01（按路由键 `ip-10.20.3.18` 对应的 SNI 路由标签转发，无 DNS）140ms 成功；带凭证升级 + E2EE 握手 96ms 成功；工作区挂载 210ms 成功。
- 成功绿点、失败红点、跳过灰点；右侧等宽耗时。
- 「查看原始诊断 JSON」可折叠展开。
- 底部「复制诊断信息」写入剪贴板并给出成功提示。

### P8 下载策略 `#/settings`

- 全局默认策略：禁止下载 / 审批后允许（二期，禁用）/ 允许下载，三选一单选卡片，默认禁止。
- 选择「允许下载」时出现警示说明。
- 例外与告警：审计告警开关、单文件大小阈值（默认 0，0 表示全禁）、项目级例外入口。
- 页面底部为吸底保存栏，展示「所有更改已保存 / 有未保存的更改」状态；保存、放弃更改均可用。
- 项目级策略仍由 P5 单独配置，并提示变更 30 秒内生效并记录审计。

### P9 403 无权限 `#/forbidden`

- 保持登录后的顶栏与侧栏，但侧栏只显示「工作台」「我的项目」，无任何管理导航。
- 居中提示：`403 · ACCESS_DENIED`、标题「无权访问」、说明「当前账号没有平台管理权限。如需访问，请联系平台管理员开通。」。
- 提供「返回工作台」按钮。
- 入口：角色切换旁的「查看无权限页」小链接。若管理员进入该页会切换为开发者视角；在开发者状态下直接访问管理路由也会被带到此页。

## 4. 全局交互规则

- 所有导航项通过 hash 切换，无刷新；侧栏当前项高亮。
- 顶部角色演示：默认管理员，可切换开发者。切换到开发者且当前停留在管理页时，自动回到工作台并提示；两侧导航即时更新。
- 全局搜索：项目结果可打开项目，主机结果可跳转到主机页并自动打开对应抽屉；开发者角色下不展示主机结果。
- 顶部通知、搜索面板、连接线路弹层、文件菜单均支持点击空白处或 Escape 关闭。
- 所有确认与提示均使用自制对话框 / 页面内提示 / toast，不使用浏览器原生 `alert()` / `confirm()`。
- 对话框支持 Escape 关闭、点击遮罩关闭、焦点回到触发元素，Tab 焦点限制在对话框内。
- 文件树行支持 Enter / Space 操作；对话框、菜单、抽屉均有关闭路径。
- 页面无横向滚动条；表格/内容超宽时在局部滚动容器中处理。
