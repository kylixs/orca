移动端适配 · 断点策略

云端平台全站 Web 面 · 375px 基准原型

断点定义

沿用同一套 DOM 与样式表，仅按视口宽度切换布局形态

≥769px桌面
481–768窄屏
≤480px手机
  • 桌面 ≥769px：现状布局不变（侧栏 + 表格 + 居中弹框），本原型不影响桌面形态。
  • 窄屏 481–768px：侧栏收为抽屉；表格保留触控横向滚动；弹框仍居中，不改卡片。
  • 手机 ≤480px：本原型形态——底部 tab 导航 + 表格卡片化 + 弹框转全屏 sheet。

导航模式

  • 侧栏 → 底部 tab：常驻「工作台 / 项目 / 审计」三个高频面 +「更多」。
  • 管理页（主机 / 中继 / 用户 / 设置）收进「更多」sheet；admin-only 守卫沿用：无权角色直接不渲染入口。
  • 顶栏全局搜索 / 通知降为页头图标入口；账号与退出移入「更多」。

表格 → 卡片列表

  • 一行 = 一卡：首行主标识 + 状态徽标；中部关键字段两列网格；尾部主操作按钮 + 次操作链接。
  • 表格计数 / 脚注 → 列表尾注行；分页 → 「加载更多」按钮。
  • 筛选 ≤3 字段 = 横向 chips；多字段（审计 10 项）= 「筛选」入口 + 全屏筛选 sheet。

弹框 → 全屏 sheet

  • 详情弹框 / 右侧抽屉 → 全屏 sheet：标题栏（返回 + 标题）+ 分段 tab + 吸底操作栏。
  • 确认类小弹框（覆盖确认 / 危险操作）保持居中小卡，不打断层级。
  • 触控目标 ≥44px，主按钮 ≥48px；滚动区带安全区 padding。

DOM 策略（终审项 T1）

响应式同一套 DOM vs 独立移动布局

推荐：响应式同一套 DOM。断点 CSS + 少量组件级分叉（表格↔卡片、弹框↔sheet）覆盖全部管理面；完整理由与边界见 prototype-mobile-notes.md §2。
  • 边界：开发工作区面（宿主 cloud-admin.html / 独立 Orca Web）不适用本策略——管理能力可移动适配，工作区内容仍桌面优先。
断点策略页为评审入口 · 完整面清单与未解问题见 prototype-mobile-notes.md
