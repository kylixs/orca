## 文档模板（每模块必含）

1. **页面/界面布局**：区域划分（导航/列表/详情/弹框/tab），文字化描述
2. **菜单与入口**：可达路径（URL/按钮/跳转），权限门槛
3. **操作清单**：全部用户操作逐条（动作→结果→弹窗/确认→失败态），含快捷键
4. **数据来源**：涉及 API/事件/存储
5. **已知缺陷**：台账 U 号链接
6. **测试覆盖**：既有 e2e/探索路径链接，未覆盖项显式标注
