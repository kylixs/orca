如何查看

直接打开各 HTML 文件。文件树中点击文件行进入预览，长按 500 ms 或点击行尾「…」打开 ActionSheet；搜索框与类型 chips 可实时筛选。HTML 预览用第二行工具栏切换 Preview / Source，右上角「…」打开同一套文件动作。

原型范围

覆盖默认、长按、选中、禁用、无权限、能力受限、下载进度 / 失败、保存与打开方式结果、搜索截断与 HTML 安全状态。手机框内英文文案是实现基准；页面中文说明仅用于设计沟通。演示数据为虚构文件与 URL。

设计约束

主题 token：背景 #111111、强调色 #3b82f6、圆角 6px。触控目标 44 × 44 或 hitSlop。所有弹层为底部 ActionSheet，不使用锚定 popover。Save to phone（Android SAF / iOS Save to Files）与 Open with（Android ACTION_VIEW / iOS 分享面板）是两个独立结果。

流程依据 remote-connectivity/design/DEVELOPMENT_PROCESS.md G2：每个需求一张主流程原型 + 关键状态。原型不代替真实 UI，但用于指导实现与 UI 评审。HTML 本期不提供外部浏览器标签页动作；只有 Preview / Source 参与 “Remember my choice”。
