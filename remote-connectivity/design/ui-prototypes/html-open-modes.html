HTML 预览、源码与打开方式

首次点击 HTML 文件时选择 Preview / Source；记住偏好后直接进入。预览/源码切换位于第二行工具栏，右上角只有一个「…」入口，打开底部 ActionSheet；外部动作来自共享文件动作模型，本期不提供外部浏览器标签页动作。
