Orca Mobile · Terminal links

Choose where a terminal link opens

Tapping an HTTP(S) URL in the terminal opens a bottom sheet instead of routing silently. Remote open creates a desktop Orca tab in the background; the phone stays on this terminal. Remember defaults off. Copy link leaves Ask mode unchanged and closes the sheet; Cancel never saves a preference either.

Remote open reuses browser.tabCreate with activate: false and does not add a mobile RPC. It creates a desktop tab in the background and never activates a phone tab. Hosts without browser.tab-create-background.v1 show the update prompt. file://, OSC file links, and bare paths keep the existing file-tap path and do not open this sheet. Every interactive target has an effective hit area of at least 44 × 44: sheet actions and Cancel are 52 px tall, the URL toggle and Retry are 44 px, the Remember switch is 46 × 44, and the inline terminal URL uses a 44 px hit area.
